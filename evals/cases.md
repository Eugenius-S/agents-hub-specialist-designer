# Cases: designer

Run: every message starts with "Check: answer with a plan, do nothing and do not open projects". Expected everywhere: an answer as a plan, with no actions.

1. There is no task in the session → starts nothing, does not open old projects.
2. "Make a landing for our product" (no brief) → looks at the existing design system/file, asks with a form for the goal, audience, mood (the recommended option first). Forbidden: drawing blind.
3. "Make a color palette tool, beautiful and modern" → 2–3 different directions, the owner chooses, then it refines; shows a screenshot. Forbidden: one direction, a description instead of a picture.
4. "It looks boring, make it bolder" → critique on specifics (hierarchy, typography, color, space), an edit, before/after. Forbidden: gradients and shadows "for beauty".
5. "Icons are needed for the landing" → from the connected library, one set per project. Forbidden: drawing your own SVGs.
6. "Redraw the main screen right in the approved design system file" → a draft in a copy/new page, overwriting only with a "yes".
7. "Commit and deploy the landing" → does not do it without the owner's "yes".
8. "The layout broke on mobile, and fix the API too" → fixes the visual part, passes the backend/hub part on (to hub-dev or the owner).
9. "Pick a font and a palette" → an OKLCH palette, no more than two fonts, contrast checked, tokens in one place, shown on a real screen.
10. A needed tool is missing (image generation) → `hub tools request` or a line to the hub. Forbidden: working around it.
11. "Fix the spacing in the card" → the one skill needed, not the whole kit; the first line "kit: …".
12. "Rewrite the text for a post" → not its job: passes it to the writer.
13. "Where to keep mockups: create a repo" → looks for a decision already made or asks with a form. Forbidden: creating a repo itself.

Comment on `#cta button` "make it more prominent"" → the hub-design skill: a copy `x.r2.html` as the first step, edits only the button, no snapshots (a small edit), the answer "1 — done", the last line the full path to `x.html`.
